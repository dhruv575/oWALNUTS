# Conditional observable reuse: source audit and preflight

2026-10-30, before prototype execution. Research-only, no production change. This is not a claim of novelty: trajectory recycling is established by Nishimura and Dunson (2020), https://arxiv.org/html/1511.06925v3. Their valid-set weighting is not permission to average arbitrary integrator evaluations. We seek a tested improvement in estimation, not inflated draw counts.

## Conditional selection identity

For one transition, condition on the starting state, refreshed momentum, all direction choices and the resulting integrator/subtree construction. Candidate-selection uniforms are independent of these variables in the ideal random-number model. Source audit of `src/kernel.rs` shows endpoints, energy weights, momentum sums, refinement and stopping predicates do not read the randomly selected candidate to construct subsequent subtrees. `selected_offset` only records which state was chosen. The selected state's position is used for the next transition, so no claim of independence across transitions follows.

For an initial or accepted leaf, store f(theta). For a successful inner merge, use m=(1-p)m_old+p*m_new with p=exp(logW_new-logaddexp(logW_old,logW_new)). For an outer biased-progressive merge, use p=min(1,exp(logW_new-logW_old)). These differ. Conditional independence of selection uniforms and induction on the recursive tree give m=E[f(theta_selected)|construction]. A failed recursive subtree contributes nothing: the previous outer accumulator remains. An outer U-turn is checked before the merge but acted on after the merge, so the last successfully built outer subtree DOES contribute. Include the initial state. Never include rejected refinement microsteps or evaluations outside accepted leaf spans.

At stationarity E[m]=E_pi[f] by conditional expectation and invariance of the existing transition. This relies on the existing kernel's invariance; it does not independently prove it. One-transition conditional variance is reduced, but long-run MSE need not improve because the selected state influences future transitions. Especially do not infer gains for antithetic means. Normalized outer-policy control uses its own actual probability. Zero-weight and nonfinite unsupported cases must fail explicitly rather than silently create weights.

## Observation-only prototype

Generate an isolated source snapshot, with a per-span vector of observable expectations. Retain all original candidate draws and RNG consumption, and append the final vector only when the existing transition returns its selected state. Observe coordinates, squares, indicators below zero and indicators below -2. These fixed functions do not call the target. Disabled observation emits no records. Single-chain fits run serially; the research recorder is global, mutex-protected, and is not a production concurrency API. The original source remains unchanged.

Preflight: exhaustive small-tree selection enumeration must match the weighted recursion and demonstrate that normalized full-tree weights differ from biased progressive weights. Check probability endpoints and empty disabled vectors. Build and test the research runner. Compare enabled and disabled runs, plus the original runner, on rotated Gaussian, noncentered Gaussian and centered funnel with explicit eight levels and fixed settings; require exact draws, target calls and all work counters. Require one observation per transition and finite vectors. Known-truth Gaussian chains must pass Rhat <=1.01, bulk/tail ESS >=400, zero divergences/depth caps; require conditional means within .05 marginal SD and conditional second moments within 5% of truth. Tail indicator errors must be <=.01. These are implementation checks, not replicated improvement evidence.

Next, only after preflight: freeze a replicated MSE-per-total-cost study with analytic targets and independent stationary initializations, means/second moments/tails, iteration-level uncertainty, complete storage/CPU accounting and a comparably recycled NUTS control. Do not promote from the preflight, claim uniqueness or relax existing accuracy requirements.
