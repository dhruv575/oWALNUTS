# Frozen tuned cold recycling comparison

2026-10-30, before calibration. Single existing 24D all-pairs curvature-5 banana, original-coordinate functions: means, second moments, probabilities below 0 and -2. Primary family: all-coordinate second moments normalized by exact variance (1,51). Separate direct and exact latent representations; all starts generated as standard normals and mapped to direct as appropriate. This is a selected synthetic mechanism study, not an application or novelty claim.

Each fit has 1,000 warmup and 2,000 retained transitions. Four configurations per sampler: WAL adaptive diagonal, acceptance .9/.99 crossed with max_error1/10, eight levels, initial step .3; native acceptance .9/.99 crossed with diagonal/low-rank, native initial step default .1, no jitter, maxdepth10. All same Rust1.99.1. Ordinary and recycled versions have separate configuration selection to avoid handicapping the baseline. Native and WAL receive equal four-configuration search budgets in each representation. No changing thresholds after results.

Calibration: 16 independent replicates/configuration/representation/estimator, four per process batch. Initial PCG64 seed 941900001; sampler seeds 941910001+replicate. Same starts and numeric seeds across candidates; different samplers do not imply common random numbers. Three randomized timing repetitions per batch, PCG64 order seed 941920001+100*representation_index+batch. Freeze all calibration inputs, sources and analysis before execution. For each sampler/representation/estimator choose the configuration with zero retained divergences minimizing normalized second-moment MSE times mean process time. If none has zero divergences, retain a diagnostic selection minimizing divergence count then that objective, mark it ineligible and veto promotion. Preserve all candidates, not just selected results.

Validation: 64 independent replicates per selected arm, PCG64 starts seed 942000001; sampler seeds 942010001+replicate. Eight selected arms (two samplers x two representations x ordinary/recycled), plus a direct independent transformed-normal draw control with 2,000 exact samples per replicate and seed 942020001+replicate. Timing order PCG64 942030001+batch, three repetitions, direct perf_counter around subprocess completion including startup, warmup, estimator computation, serialization and file close (not fsync). Replays must match canonical outputs excluding only seconds. Timing repetitions are not independent statistical replicates. Warmup is excluded from estimates and included in all costs. Report single-fit costs and calibration cost amortized across the 64 validation fits separately. Charge one measured calibration pass (mean timing across repetitions) for every searched candidate; report actual three-pass research expenditure separately. Independent draws need no calibration.

Primary ratios: comparator MSE / direct recycled WAL MSE, and comparator total cost / direct recycled WAL total cost; product above one favors WAL. Bootstrap whole replicate vectors 10,000 times (PCG64 942040001) and whole timing batches 10,000 times (942050001). Endpoint-product ranges are descriptive, not joint confidence intervals. Primary competitive promotion requires eligible selections, zero retained validation divergences, all primary coordinate aggregate error |z|<=4.5, and adjusted lower endpoint >1.2 against every selected native arm and every exact-coordinate/independent-draw control, under both single-fit and calibration-amortized costs. Also report improvement relative to ordinary WAL without calling it competitive superiority. Keep all functional families and regressions; no rescue seeds.

Report per-coordinate block-MCSE coverage (40 blocks of50), aggregate errors and divergences. Full-output validation replay for first batch of all eight sampler arms must reproduce compact summaries; compute raw Rhat/ESS there. Those subset diagnostics are not full validation qualification and cannot substitute for replicated known-truth error. If a competitive efficiency gate passes, require a further all-batch posterior-diagnostic audit before promotion. An efficiency failure needs no enlarged sampling to explain it away. Only a subsequent qualified nonanalytic application could establish a useful application.
