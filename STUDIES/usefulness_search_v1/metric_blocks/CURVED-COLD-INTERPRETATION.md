# Tuned curved cold comparison: promotion rejected

2026-10-30. The frozen competitive gate fails. On held-out direct-coordinate second moments, recycled WAL has MSE 0.018285 versus ordinary WAL 0.019879, a 1.087x MSE ratio. Its extra cost removes that benefit: adjusted ratio 0.984, descriptive endpoint range 0.955-1.015; including calibration amortized over 64 fits gives 0.983 (0.957-1.010). This is not a useful direct-coordinate runtime improvement. Both WAL versions independently selected the same .9 acceptance/error10 configuration, so this within-WAL comparison also preserves identical underlying draws and calls.

Direct native controls have worse point MSE but extremely wide uncertainty. Against recycled native, the WAL-favoring adjusted ratio is 1.995 with range 0.246-5.404; ordinary native gives 1.431 (0.192-3.842). These ranges do not establish a win. Post-hoc inspection found that replicate44 accounts for 85.1%/86.3% of ordinary/recycled direct-native squared error, versus 6.1%/5.8% for WAL. No replicate is removed. The MSE-times-target-calls ratio against recycled native is 3.995 with paired bootstrap interval 0.501-10.824; that is likewise inconclusive and is not evidence for an expensive-likelihood application. Native used fewer target calls on average (321,384 vs WAL 439,373), unlike the earlier differently tuned/budgeted curvature study.

Exact-coordinate controls dominate the raw-coordinate proposal. The single-fit WAL-favoring adjusted ratios are 0.01459 against latent recycled WAL, 0.01116 against latent recycled native, and 0.002315 against exact independent draws. These correspond to point efficiencies about 69x, 90x and 432x in favor of those controls on this finite-budget MSE-times-cost measure; they are not universal speedups or asymptotic efficiency claims. Calibration-amortized accounting does not reverse the conclusion. The exact transform is available for this synthetic target, so a raw-coordinate comparison cannot establish a useful application.

All selected candidates were eligible (zero calibration divergences), and all validation arms had zero retained divergences and aggregate mean-error |z| below3.37. First-batch raw diagnostics passed conventional thresholds, but they cover only that batch. Minimum per-coordinate nominal95% block-MCSE coverage across64 runs was 0.781-0.891 for sampler arms and0.875 for exact draws. These minima over96 functions are descriptive, not a simultaneous coverage test. Uncertainty remains limited, especially for heavy-tailed squares and the rare native outlier. Known-truth replicated errors, not favorable first-batch diagnostics or zero divergences, determine the failed conclusion.

The equal four-configuration searches produced32 candidates with16 calibration replicates each. Validation used64 independent replicates per eight selected sampler arms plus exact draws. All384 calibration and432 validation timing invocations reproduced canonical outputs; nine full first-batch replays matched compact summaries. Timing repetitions are not statistical replicates. Native default backward compatibility passed eight exact replay cases. The exact-draw helper's first build failed because rand's ChaCha feature was not enabled; the failed manifest/log and corrected build are preserved. No statistical protocol changed.

Costs include process startup, warmup, summaries and serialization. Research instrumentation is not identical: WAL emits detailed metadata/telemetry, whereas observed native computes both ordinary and conditional summaries and hashes warmup as well as retained draws. These costs are measured as executed, not presented as intrinsic sampler costs. Their effects require measurement before any fine-grained implementation claim. Calibration costs use a one-pass mean and are amortized across64 fits; actual three-pass timing expenditure is recorded separately. Exact draws have no tuning cost. Product endpoint ranges are descriptive rather than calibrated joint intervals.

## Next reviewed work

Close the curved recycling promotion branch; do not add seeds or retune to rescue it. Preserve replicate44 and, if needed, replay that existing batch solely to diagnose the native error concentration, not as a new replicate or revised gate. Audit previous runtime/overhead profiles before proposing a new implementation improvement. The next useful candidate should address measured cost or inference failure with a clear mechanism and fresh validation; another undirected application sweep or naive averaging of extra microsteps is not justified. Existing tree-selection recycling does not authorize including microsteps absent from the actual selection law. A useful algorithm improvement and a nonanalytic application remain unproven; the manuscript must retain these negative results.
