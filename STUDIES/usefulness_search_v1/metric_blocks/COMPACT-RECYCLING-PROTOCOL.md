# Compact estimator output implementation guard

Frozen before execution, 2026-10-30. The full recorder improved some Gaussian MSEs but its serialization cost erased most gains. Implement a research-only compact mode for both ordinary and conditional estimators. No production changes or statistical success claim.

In conditional mode, aggregate one vector per original transition into overall sums and consecutive blocks of 50 transitions, retaining each block's actual size, including a final partial block. Do not store the full conditional record. The existing sampler still retains its ordinary draws internally: do not call this a constant-memory sampler. In ordinary compact mode, apply identical observables and aggregation to those retained draws. Both modes return the chosen estimator's mean, block means/sizes, chain metadata and work counters, and SHA256 of all underlying draw f64 little-endian bit patterns. Both omit raw draw arrays from compact output. Keep full-output mode for verification. Block means are correlated summaries, not automatically independent samples or proof of convergence.

Use the actual fixed dense coordinate map before evaluating nonlinear observables. Check 0/1/final partial block handling and finite-input failures. Preserve prior raw records and binaries. Preflight replays all 48 existing target/batch cases in both compact modes (96 workers). Verify SHA256 against preserved raw draws, metadata and work parity, overall means and every block mean/size against independent Python calculations (rtol 2e-13, atol 1e-10), and count=1,000. Additionally compare full mode to the previous full observer on one batch per target, with exact draws, observable vectors and emitted work. Unit tests cover partial blocks and empty-input rejection. These replays are not fresh statistical evidence.

Only after preflight freeze fresh stationary-start replicate seeds and direct randomized paired timing. Use the same target/settings and all prespecified functionals as the prior screen. Equally compact ordinary output is the cost comparator. Preserve a full-mode validation subset on fresh inputs. No practical-superiority claim without independent confirmation and comparably recycled native NUTS controls.

Bound builds at 300 seconds/4 GiB, dependency resolution/fetch separately at 120 seconds/2 GiB; pin SHA256 dependency and preserve lockfile. Run each fit at 180 seconds/2 GiB/64 MiB, one at a time, disk floor 1 GiB. Archive source, binaries, failure evidence, outputs and hash readback locally.
