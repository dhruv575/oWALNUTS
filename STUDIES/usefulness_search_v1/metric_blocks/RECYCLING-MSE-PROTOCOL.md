# Fresh replicated recycling MSE screen

Frozen before execution, 2026-10-30. This is an exploratory efficacy screen of the verified fixed-metric observer, not confirmation, cold-workflow evidence or superiority over native NUTS. No tuning changes or post-result extensions.

Three analytic targets: the two-dimensional rotated Gaussian with covariance [[2,1],[1,2]], the ten-dimensional noncentered Gaussian (first variance 9, others 1), and the ten-dimensional centered funnel with omega SD 3. Use fixed diagonal identity mass for the latter two and the exact inverse covariance as dense mass for the rotated Gaussian. Step .3, eight levels, error threshold 1, no warmup. For each target, draw 64 independent exact stationary initial states with NumPy PCG64 seed 941300001 + target_index; centered funnel states are (omega, exp(omega/2)*z). Run 1,000 transitions per replicate. Rust chain seeds are 941310001 + 1000*target_index + replicate_index. Four independent replicates per bounded job. Run original and observer-enabled binaries in alternating order by batch, require exact original/observed draws and every emitted work counter, and preserve all outputs. No reruns for statistical failures.

Score every coordinate's mean, second moment, P(x<0), P(x<-2). Gaussian truths are analytic. Funnel first-coordinate truths are Gaussian; others have mean 0, second moment exp(4.5), P(x<0)=.5, and P(x<-2)=integral Phi(-2 exp(-omega/2)) N(omega;0,9) d omega. Independently verify this last quadrature at two tolerances and via a second integration parameterization. Heavy-tailed second-moment results must be reported with their uncertainty and instability; do not drop them to improve an aggregate.

Compute ordinary and conditional estimates on the same chains, and squared errors against truth. Report each functional's MSE ratio ordinary/conditional and paired-replicate bootstrap 95% percentile intervals (10,000 resamples, seed 941320001). Also report each target/family aggregate, normalizing mean errors by marginal SD and second-moment errors by marginal second moment; probability errors are unscaled. Bootstrap whole replicate vectors, not coordinates or recycled points. Report first-half/second-half MSE ratios and mean-error z statistics across independent replicates, flag |z|>4.5. These exploratory intervals do not provide multiplicity-adjusted confirmation.

Primary cost-adjusted ratio divides the MSE ratio by observed/original summed bounded-worker elapsed time (including startup, sample serialization and file output). Also report sampler-internal time and output bytes separately. This cheap-target prototype has extra storage/locking costs; do not quote gradient-count equality as zero cost. Costs and MSE must be reported together. Per-chain sampled health events are descriptive here; exact stationary starts make this a finite-run estimator study, not proof of warmup/convergence for an application.

A candidate observable family merits a separate held-out study only if its MSE-ratio lower interval exceeds 1.2, its cost-adjusted lower interval exceeds 1, and no member has an aggregate-bias flag. A general replacement claim additionally requires no family regression below .9; otherwise any continuation must be explicitly observable-specific. Passing this screen is not goal completion: qualified strong native/recycled NUTS controls and application-relevant value remain required. A failure closes the current cost/target proposal unless a concrete distinct mechanism justifies further work.

96 sampling workers: 3 targets x 16 batches x 2 arms. Sequential, 180 seconds/2 GiB/64 MiB per worker, 1-GiB disk floor. Preserve source/binary hashes, all draws, settings, failures, supervision, independent replay and local archive readback. No cloud spending or production changes.
