### WP30-KERNEL-GAP-V1 -- the per-gradient gap to NUTS on ordinary posteriors is leaves per orbit under the endpoint U-turn statistic; `MomentumSum` recovers 0.77x -> 0.90x at matched step, metric and starts
- Ordered time: 2026-09-02 on `wt/kernel-gap`; matched-condition instrumentation study, not preregistered (attribution and candidate generation; no default flipped).
- Protocol/config: six posteriordb models (`earnings`, `kidiq`, `mesquite`, `nes2000`, `garch11`, `arK`; `28f8d3d`, BridgeStan without `STAN_THREADS`). CmdStan 2.39.0 once per model (defaults, seed 84200); each chain's adapted `stepsize__`, inverse metric and first retained draw (unconstrained via BridgeStan) are the fixed step, `M^-1` and start of that chain in every arm. No warmup, 4 x 2,000, depth 10. Arms: reference NUTS (`examples/support/reference_nuts.rs`, Stan `base_nuts` 2.21+), oWALNUTS through `Sampler` (`Adaptation::None`, `Metric::fixed_diagonal`, four levels, `delta = 1`, cache) with `Endpoints` / `EndpointsWithCross` / `MomentumSum`, `delta = 1000`, one level + `AcceptUnlessDivergent` (with and without `MomentumSum`), four levels + `AcceptUnlessDivergent`. Metric: minimum bulk ESS over unconstrained coordinates per gradient, decomposed as ESS per orbit x 1 / (leaves per orbit x gradients per leaf); per transition the stop cause, orbit size and the selected/initial state indices (new diagnostics). Ratios to the reference on the same seed, seed medians, geometric mean over models.
- Seeds: 84201-84202 (fresh); CmdStan 84200; funnel 252601-252603 (fresh). Deviations: none; 96 cells ran once (`artifacts/table-run.log`).
- Status: instrumentation study; no default flipped; no new kernel rule (the existing opt-in `UTurnRule::MomentumSum` is the prototype).
- Outcome: the reference NUTS reproduces CmdStan's own run (leapfrogs per orbit 158/29/49/50/11/33 vs 155/29/50/49/11/33). Default kernel geomean 0.77x the reference per gradient = 0.46x ESS per orbit x 1.66 orbits per gradient, with leaves per orbit 0.60x (0.26x earnings, 0.49x kidiq, 0.67x nes2000, 0.70x garch11, 0.82x mesquite, 0.92x arK) and gradients per leaf 1.01x; 41-69 % of orbits end in the recursive endpoint U-turn. `delta1000`, `levels1`, `accept` are within 1 % of the default (refinement engages on 0.1-0.7 % of leaves; non-leaf gradients 0.04-0.19 per orbit); `EndpointsWithCross` 0.69x. `MomentumSum`: leaves 0.97x (0.95-0.98 per model), ESS per orbit 0.88x, ESS per gradient **0.90x** (0.84-0.96); `earnings` 40 -> 151 leaves per orbit (reference 158). Control `levels1+rhosum` 0.95x per gradient, 0.997x leaves, selected-state relative displacement 0.51-0.56 as the reference: no selection difference. The 0.90 -> 0.95 residual is refinement's reverse-coarser orbit stops (3-7 % of orbits at `delta = 1`). `uturn_default_v1` measured `MomentumSum` at 1.12x geomean on these six under the default warmup; the 1.06x/0.78x that rejected it came from the other eleven models under the unit-floored metric or the depth cap. Funnel (3 seeds pooled): `MomentumSum` z -0.5 (paper tuning) and -0.3 (sampler defaults); `Endpoints` +2.2 and -3.8 on these seeds (the defaults result differs from WP28's three seeds; batch-means s.e. underestimated).
