## Rank diagnostics: useful, but not a shortcut

calibration.py expects legacy chains/raw report layout and uses ESS-based spacing plus KS p-values. ESS spacing is not proof that retained posterior draws are independent, so its ranks cannot be relabeled exact SBC. It also combines selected healthy fits, which can distort the rank distribution. A new adapter should extract the same14 physical functionals from current canonical arrays, save chain labels/tier/ESS, and preserve all intended cases and rank-unavailable reasons. Use common predeclared rank sub-sampling streams, never truth-selected draws.

Treat rank histograms/ECDF and autocorrelation-sensitive checks as secondary diagnostics unless a defensible rank-reference law for the finite correlated chains is supplied. More posterior draws cannot be assumed independent because thinning was applied. A small fixed number of independently initialized posterior chains with one post-warmup draw each offers a clearer replication unit but still depends on convergence; it does not magically create exact posterior samples. For the four forecasts, observed probability-integral-transform diagnostics are also secondary and must include posterior/predictive integration uncertainty. The primary exact-binomial repeated-dataset coverage analysis avoids pretending correlated retained draws are iid rank samples.
