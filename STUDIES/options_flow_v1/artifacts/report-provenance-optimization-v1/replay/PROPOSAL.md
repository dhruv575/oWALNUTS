## Separate two provenance roles

Historical seed search is pre-generation evidence: searched files/bytes, their digests, exclusion policy, exact stream list, collisions and auditor. The search must be revalidated BEFORE generation/freeze. Once accepted, preserve the exact bounded searched bytes in an immutable evidence archive, or bind an existing complete archived corpus plus reproducible subset manifest; archive the token scanner and seed audit. Subsequent fitting/reporting should bind this archived evidence and the acceptance manifest, not require unrelated live historical files to remain byte-identical forever. This is a prospective protocol change, not a retroactive weakening of current frozen experiments.

Runtime source bindings are the actual imported controller/worker/adapter/report Python (including subpackages), Rust source/build attestation, executable/extension, dependency/runtime identity, fixtures, protocol/intent, and accepted seed-evidence archive/manifest. These remain required at the declared boundaries. Source discovery checks detect newly added relevant Python files; a hash map alone does not catch additions. Retain both path-to-byte identity and archive relative-path mapping. A ZIP checksum without verifying its entry mapping at acceptance is insufficient.

Without a complete evidence archive, leave the existing live historical bindings unchanged. A compact audit digest proves what was asserted, not that the originally searched bytes remain reproducible. For the already frozen40-cell result use its archived original source/procedure contract; do not rewrite bound_files or relabel posthoc optimized reporting as the original cost.

## Cohort reporting transaction

Implement an explicit shared-validation context owned by normalize(manifest) or, preferably, the controller's report() across both public/reference manifests. Build the union of required shared bindings; reject any path with conflicting expected hashes. Hash each shared file once at transaction admission. Read fixed per-cell fixtures, statuses, hardware, report/checkpoint/raw metadata with current cell identity checks unchanged. Reuse normalized expected maps/procedure digests derived from already loaded immutable manifest objects; do not cache mutable file digests based merely on size/mtime.

After every cell has been normalized, hash the full shared set once again and verify source inventory membership. Recheck the concrete per-cell artifact hashes used during normalization before publication (or retain existing per-cell end checks); large raw files retain the same hash obligations as the old adapter. Write provisional results to a new temporary/attempt directory, then publish finalized records only after the cohort postcheck. Never expose provisional usable=True as the authoritative final report.

If admission/shared postverification fails, every intended record is retained with provenance_valid=False,usable=False and explicit shared_provenance_failure; preserve any original failure classification, raw/worker/controller status, all known cost fields and normalization diagnostics. Do not convert a timeout into an algorithmic convergence failure. A malformed single cell remains a local invalid record while the rest may be admitted if shared checks pass. All outputs keep qualified=False. The reporting controller records admission, normalization, final verification, serialization and total costs, including exceptions.

This changes the temporal validation boundary from per-cell to an explicit whole-cohort transaction. It preserves required content equality at admission/completion and fails the entire cohort on shared drift. It is NOT literally equivalent to every intermediate hash: a transient mutation restored before the postcheck can escape either sparse scheme, with different opportunities for detection. Do not claim stat-cache equivalence or continuous monitoring. If exact prior per-cell observation times are required, keep old validation for old manifests; introduce a new versioned batch-validation policy only for prospective manifests. A source snapshot used for all normalization code/data reads can further constrain this risk, but live execution must still be checked against its frozen snapshot.

Expected structural saving with old large bindings under new transaction: shared hashing drops from≈80passes to2passes (potentially4if separate manifests), plus two fixed source inventory enumerations. Actual speedup must be measured after an archived-source, saved-output correctness comparison; it cannot be inferred as40×total speedup.

## Required validation before adoption

1. **Static cohort equivalence:** legacy and proposed reporters consume the same preserved successful, unhealthy, timeout, missing and exception fixtures. Compare all normalized scientific fields, full intended IDs, failure classifications, endpoints, gates and costs; new reporting-overhead metadata may differ. Include actual saved public+associative reference artifacts without resampling.
2. **Shared precheck failure:** modify a runtime source or accepted evidence archive before normalization; all intended rows invalid, no usable results published, costs retained.
3. **Shared mid-cohort mutation:** mutate after the first cell, leave changed; final hash detects it and invalidates BOTH early and later rows. Test same-length content with restored mtime to prove no stat-only cache.
4. **Source addition/removal:** add an importable nested source after admission; final inventory-set check rejects. Archived historical copies outside runtime source roots do not count as runtime additions.
5. **Conflicting manifests:** two procedures name one shared path with different digests; reject before processing, preserve entire denominator.
6. **Local artifact mutation:** replace fixture/report/raw-tail/canonical-start artifact between read and finalization; detect without treating other independent local failures as successful. Maintain legacy raw hash scope; do not silently drop reference whole-file hashes.
7. **Failure-cost preservation:** injected admission/read/postcheck/serialization errors retain measured consumed time; missing costs remain unknown, not zero. Cleanup failures never produce a completed transaction.
8. **Operation count test:** with a counting hash function, shared file digests occur exactly once before and once after the cohort; cell-local artifacts retain required checks. No module-global cache leaks between separate reports.
9. **Legacy dispatch:** old manifests retain the original validator unless explicitly run as a labeled posthoc alternate analysis against immutable archived evidence. The original2157.53s remains in the frozen experiment record.

No source modifications, benchmarks or repeated raw reads were performed for this proposal. The first implementation should be a narrow validation-context seam plus an explicit provenance schema split, not another execution framework.
