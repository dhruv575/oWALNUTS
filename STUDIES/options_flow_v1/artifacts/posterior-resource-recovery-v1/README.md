Analyze the original public fits 0 and 3 from the demanding posterior resource
pilot after fixing the adapter's package-path comparison. No sampler is invoked
and no new random sampling streams are allocated. Original failed statuses and
costs remain immutable; this is additional posthoc processing, not a successful
rerun of the original resource workflow.

Each analysis reads the exact raw draws, fixture and sampler report bound by
the independent terminal audit. The archived study sources are extracted and
checked against both the original plan and its source ZIP. Recovery code is
separately bound. The same 4k/8k prefixes, all 1,012 canonical coordinates,
14 physical functionals and four forecasts are checked, followed by the same
group-zero observed predictive CDF calculation at the actual fixture covariate.

Run exactly two contained analyses on CPU 0, each capped at 1,800 seconds and
8 GiB process committed memory. The shared allowance is 3,600 seconds with a
15-second cleanup reserve. Preserve failed/unstarted outcomes and separately
measured additional costs. Output paths are new and no retry is automatic.

Passing these checks would complete missing diagnostic and resource information
from the pilot; it would not establish reference-bank accuracy, improve the
original completion denominator, or create a clean uninterrupted-workflow speed
comparison. Pilot draws remain excluded from the future independent bank.
