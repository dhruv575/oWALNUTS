# A compute route toward richer market intervals

The highest-value next step is **structured block inference**, with oWALNUTS as the general-purpose nonconjugate block engine. It is a larger change than making one likelihood evaluation 13–15% faster. This prototype is an exact alternative algorithm for a NEW synthetic model; it is not evidence that the existing oWALNUTS kernel improved.

## Concrete model and prototype

At every regular time step, latent return mean h[t] follows a Gaussian AR(1) with fixed rho=.98 and stationary initial variance q/(1-rho^2). Observed return y[t] is Student-t5 with location h[t]+beta*x[t] and scale sqrt(r). Priors: beta~N(0,.5), q~InverseGamma(3,.04), r~InverseGamma(3,.18). No observation likelihood is applied at a missing row; latent transitions still advance. The synthetic panel has512steps,412observed returns and100missing rows. This is a persistent conditional return mean, not an efficient-price level, stochastic-volatility process, causal order-flow model or validated market model.

An exact auxiliary representation uses lambda[t]~Gamma(2.5,2.5) and conditional Gaussian noise r/lambda[t]. Each Gibbs sweep draws the entire h path with forward-filter/backward-sampling (FFBS), beta from its Gaussian conditional, q/r from inverse-gamma conditionals, and observed lambdas from their gamma conditionals. Each sweep costs O(T), with no trajectory and no handwritten gradients. The Gaussian filter likelihood and smoother moments were checked against independent dense multivariate-normal oracles; missing placeholders, including NaN, have zero effect and do not compress the grid.

The same marginal model is compared with centered NumPyro, associative noncentered NumPyro, and public PyMC-to-Numba oWALNUTS. Four chains,1000warmup,4000retained draws, one CPU,180seconds per arm,8GiB cap. All515canonical coordinates are checked, alongside beta, both scales, terminal latent state and one-step observed-return interval at declared future x=0. Synthetic development seeds are recorded; this is not a fresh qualification campaign. All costs and failed preflights are retained.

## Ranked routes

1. **Blocked/hybrid inference for structured market models.** Use FFBS for conditionally Gaussian state paths and oWALNUTS for genuinely nonconjugate parameter blocks. Model-aware Student-t augmentation is exact, unlike a Gaussian likelihood approximation. The current synthetic blocked sampler is directly executable and tests full posterior mixing, including scale/path coupling. Falsification: required endpoint precision remains expensive after adequate draws, or independent samplers disagree beyond Monte Carlo uncertainty; a fast conditional-path draw alone is insufficient.
2. **Parallel continuation across chains.** Current `src/sampler.rs` rejects continuation threads other than1, while ordinary sampling already supports parallel chains and thread-independent output. An implementation can preserve each chain's RNG/state and advance chains concurrently. This can improve general-model latency without changing its statistical model. It consumes more CPU and is limited by the slowest chain; it is not a universal fourfold gain. Require chunked/uninterrupted and1/4-thread bit identity, cancellation/cleanup tests, then full workflow latency at the same interval precision. This is likely the most direct general oWALNUTS product improvement.
3. **Marginalize Gaussian state blocks where justified.** A Kalman likelihood eliminates Gaussian paths from a global-parameter HMC target and reconstructs states afterward. Robust observations can be conditionally Gaussian after augmentation, but integrating out states does not also remove all mixture variables. Nonlinear stochastic volatility is not exactly Gaussian and cannot use this shortcut unchanged. Compare collapsed versus blocked representations on the same target and actual endpoint uncertainty before choosing automatically.
4. **Joint arrival/return state model.** A logistic arrival model can use Pólya–Gamma auxiliary variables so that a Gaussian latent liquidity state has Gaussian conditional pseudo-observations from both arrivals and returns. This is a plausible route to model absence of trades as an outcome rather than discard it. It needs a validated auxiliary-variable implementation and generative/held-out calibration; it is not implemented or demonstrated here. For pooled order flow predicting underlying returns, independent underlying-price acquisition remains necessary.

## Integration boundary

Do NOT mutate callback data underneath a retained oWALNUTS session: its target must remain deterministic for its lifetime, and cached log densities/gradients would otherwise be stale. A legitimate hybrid needs a block-transition API that explicitly installs a new conditioning state at a transition boundary, recomputes target caches, and uses a valid frozen proposal/adaptation policy. Alternatively expose specialized FFBS/Gibbs as a model-aware backend while retaining oWALNUTS for unconjugated models. A product can offer both without mislabeling specialized Gibbs as an oWALNUTS kernel speedup.

The wiki's state-space findings already identify global/path coupling as the main mechanism and warn that prior noncentering can move rather than solve difficult geometry. This route addresses that structure directly. Read `wiki/findings/state-space-targets.md`, `wiki/sampler-path-redesign.md`, and `src/sampler.rs` around `start_session`.

## Scope and next decision

One regular synthetic panel cannot establish calibration, a market edge, robustness to volatility regimes, or generic sampler superiority. The practical question is whether a model-aware block interface earns enough full-workflow improvement to justify implementation. Preserve all-coordinate health and predictive precision; report any initial fixed-length failure. An eventual real-data model must use causally available covariates and explicit arrival/missingness assumptions. No existing36-fit comparison is launched or modified by this work.
