# Marked-flow feasibility

The read-only September export audit found all 201,712 trades had parseable put/call, expiry date, strike and valid contemporaneous trade-provided index price, amount and direction. Result JSON contains fixed coarse bucket counts and signed/total raw amounts, exact script and input hashes, and the original complete terminal record.

This is schema feasibility, not predictive evidence. Calendar-date maturity is not exact settlement time. Raw BTC amounts are not option delta exposure; no future prices or Greeks were introduced. Historical exchange fields do not prove live receipt-time availability. No model fit or acquisition occurred.
